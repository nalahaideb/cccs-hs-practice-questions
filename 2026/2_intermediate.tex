\item
  Given the coordinates of the corners for 2 rectangles, find the area of the 2 rectangles.

  
  \includegraphics[scale=0.45]{images/coords.png}

  
\begin{consolethree}
Example 1:
Input: -3, 0, 3, 4, 0, -1, 9, 2
Output: 45
Explanation:
6*4 = 24 and 9*3 = 27 would be 51, but they overlap.
The overlapping area is 3*2=6, so the total area of the rectangles is 45.
\end{consolethree}

\item You are given an array of intervals, each element of this array is another array with length 2 that specified the start and end of the interval as follows: [start, end]. Your goal is to merge any overlapping intervals.

\begin{consolethree}
Example 1:
Input: [[1,2],[2,3],[3,5],[8,18]]
Output: [[1,3],[3,5],[8,18]]
Explanation: Since intervals [1,2] and [2,3] overlap, merge them into [1,3].

Example 2:
Input: [[1,5],[4,9]]
Output: [[1,9]]
Explanation: Intervals [1,5] and [4,9] are considered overlapping.

Example 3:
Input: [[0, 10],[1,2], [3,4], [4,5]]
Output: [[0, 10]]
Explanation: All intervals overlap with [0,10]
\end{consolethree}

\item Given a string consisting of words separated by spaces, modify that string according to Goat Latin rules.
\begin{itemize}
\item If a word starts with a vowel, add \lq\lq ma" to the end of that word\\
  \lq\lq\texttt{apple}'' becomes \lq\lq\texttt{applema}''
\item If a word starts with a consonant, move the first letter to the end of the word and add \lq\lq ma''\\
  \lq\lq\texttt{goat}'' becomes \lq\lq\texttt{oatgma}''
\item Add n \lq\lq a'''s to the end of each word, where n is the word's index + 1
\end{itemize}

\begin{consolethree}
Example:
Input: "goats eat apples"
Output: "oatsgmaa eatmaaa applesmaaaa"
\end{consolethree}
